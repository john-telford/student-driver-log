Installed, not native

There is no iOS client codebase yet — the architecture doc scopes it as a later effort. What ships on iPhone today is the same web app added to the home screen: display: standalone, portrait, theme colour #006B3C, launched from the steering-wheel icon.

So this kit is the phone-width layout of the real screens, not a new design: the green bar keeps its yellow rule, the hamburger is the app's own 2.5px glyph, and the nine-column report defers to the PDF route.
