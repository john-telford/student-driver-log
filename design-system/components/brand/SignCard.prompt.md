Wraps a whole screen's content in a highway guide sign: 6px white frame, 3px black keyline, 17.6px outer radius, 19.2px inner green panel.

```jsx
<SignCard>
  <BrandMark variant="shield" size={80} />
  <h1>Student Driver Log</h1>
  <Input onGreen /> <Button variant="onGreen" fullWidth>Sign In</Button>
</SignCard>
```

Only one per screen, centred on white. All text inside is white; the only non-white colour is highway yellow.
